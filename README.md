✨ CALCORA – Calculate Everything, Learn Every Step

CALCORA is a modern, all-in-one calculator application designed to make everyday calculations, academic problem-solving, and specialized mathematical tasks easier and more accessible. It brings multiple calculation tools together in one beautifully designed, user-friendly application.

🎯 Project Purpose

The main purpose of CALCORA is to provide students and general users with a single platform for different types of calculations. Instead of installing multiple calculator applications, users can access essential academic, scientific, financial, and everyday calculation tools in one place.

🚀 Advantages
- **All-in-One Solution:** Multiple calculators in one application.
- **Student-Friendly:** Specially designed to support academic calculations.
- **Offline Support:** Use essential features without an internet connection.
- **Easy to Use:** Simple navigation and organized calculation categories.
- **Time-Saving:** Quick access to different calculation tools.
- **Customizable Experience:** Multiple themes and appearance settings.

🛠️ Technology Stack
- **Programming Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **Architecture:** Modular Android Architecture
- **Local Storage:** SharedPreferences / DataStore for app preferences
- **Calculation Engine:** Custom offline calculation logic
- **Development Environment:** Android Studio

🔒 Privacy & Offline Approach

CALCORA is designed with an offline-first approach. Its core calculation features work locally on the device without requiring an online account, cloud database, or external calculation API.
